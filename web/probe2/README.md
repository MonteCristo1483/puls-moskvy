# D2b — пастельная диорама, проба языка

Статическая мобильная проба 390×844: карта-диорама с баблами расстояний,
кольцами негатива и шторкой объекта. Три состояния и две атмосферы —
через query: ?s=1|2|3 (спокойное / слои / карточка), ?m=day|eve.

Съёмка: cd web && node probe2/shoot.mjs — 4 PNG и видео в web/shots/,
плюс замеры: высота хрома, минимальный шрифт, зоны нажатия, контраст.
bg.png — приглушённый CSS-фильтром live-after-f2.png, в git не входит;
это проба языка и «flow», не продакшн.
