# web/probe — D2a, дизайн-проба

Один статический экран «Пульса Москвы» в трёх визуальных языках:
`?v=a` — приборная панель (графит, моно, один сигнальный оранжевый),
`?v=b` — нейтральная точность (как сейчас), `?v=c` — чертёж (бумага, тушь).
Next эту папку не собирает: это макет, а не часть `app/`.

Тексты и цифры настоящие: карточка — запись из `web/public/live/works.geojson`
(data.mos.ru, набор 2855, выгрузка 27.11 19:22 МСК), погода — Open-Meteo.

    cd web
    node probe/shoot.mjs      # шесть PNG в web/shots/d2a-*.png + замеры мобильного вида
    node probe/shoot.mjs a c  # только нужные языки

`shoot.mjs` копирует `web/shots/live-after-f2.png` в `probe/bg.png` и печёт из
него чистые кропы `bg-desk.png` / `bg-mob.png` — в подложку не попадает
интерфейс приложения. Все `web/probe/*.png` рабочие и лежат в `.gitignore`.
