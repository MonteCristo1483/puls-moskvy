## Правила и грабли (не наступать снова)

- **Ветка — только от свежего `origin/main`.** Ветвление от рабочей ветки дало конфликт modify/delete и потерянный час: `main` удалил `map.tsx`, а ветка его правила.
- **Существующие тесты править нельзя.** Если для фичи нужен другой контрол — делать новый примитив (так появился `ChipButton` на `aria-pressed`).
- **Не верить отчётам агентов.** Оркестратор сам гоняет `tsc`/`build`/`e2e` и сравнивает скриншоты попиксельно (уже пойманы: пропавшая галочка в чипе, тест, падавший по своему таймауту 30 с, deep link без камеры).
- **Пути с кириллицей + Python = смерть сессии.** Агент упал, анализируя палитру скриптом (в путях `Р”РѕРєСѓРјРµРЅС‚С‹`). В брифах: без Python, без анализа цветов, цвета и данные давать готовыми.
- **Autopilot** мержит PR и вызывает Deploy. Если PR `dirty` — не force-push (запрещён), а перенести итоговое дерево на свежий `main` новым коммитом.
- **Один раз был прямой пуш в `main`** (PR не мержился, логи Actions без токена 404). Обход записан в `DECISIONS`; повторять только с согласия владельца.
