# DECISIONS — журнал решений

Формат: дата — решение — почему.

- 2026-11-27 — **Заморозить «Карту окружения дома», начать новый продукт.** Старый репозиторий остаётся как движок и прод-референс; разработка там остановлена. Почему: продукт упёрся в противоречие «индекс адреса» vs «ситуация в городе», а переделка на месте тянула хвосты (документы, скоринг, позиционирование).
- 2026-11-27 — **Новый репозиторий `puls-moskvy`, публичный, ветка `master`.** Перенесён только движок (`web/`, `pipeline/`, `config/`, CI), без данных, `node_modules` и артефактов сборки. Почему: публичный нужен для бесплатного GitHub Pages; закроем при переезде на свой хостинг.
- 2026-11-27 — **Название: «Пульс Москвы».** Отражает ядро — состояние города, а не оценку адреса.
- 2026-11-27 — **Ядро продукта — «что происходит сейчас»**, адресный балл остаётся слоем, а не центром. Почему: владелец выбирает между «найти ужас рядом» и «понять город»; выбран второй — у него есть повторный сценарий, у первого нет.
- 2026-11-27 — **MVP без бэкенда:** GitHub Actions cron + JSON в артефакте Pages, погода запрашивается из браузера. Почему: один человек, нулевая стоимость; бэкенд вводим только если S1 докажет необходимость.
- 2026-11-27 — **Пробки, афиша и замеры воздуха — вне MVP.** Почему: закрытые/платные API и отсутствие сенсоров; обещать «в реальном времени» без источника нельзя.
