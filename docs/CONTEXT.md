# CONTEXT — Пульс Москвы (обновлять в конце каждого блока работ)

**Что это:** интерактивный слепок Москвы на открытых данных — «что происходит в городе сейчас».
**Репозиторий:** https://github.com/MonteCristo1483/puls-moskvy (публичный, ветка `master`).
**Старый проект** (`karta-okruzheniya`) заморожен: остаётся как движок и прод-референс, разработка не ведётся.

## Что уже в репозитории

- `web/` — Next.js + MapLibre + PMTiles, 3D-дома, PWA (перенесено из старого проекта как движок).
- `pipeline/` — OSM → PostGIS → скоринг → экспорт → tippecanoe.
- `config/scoring.json` — индекс по 7 факторам (транспорт, промзоны, доступность, зелень, дом, плотность, ветер).
- Данных в репозитории нет: они в Release старого проекта, для нового ещё не заводились.
- Бэкенда нет, деплоя нет (Pages не включён).

## Документы

- `docs/BRIEF.md` — контекст и ограничения.
- `docs/PRODUCT.md` — позиционирование, персоны, MVP (4 блока), метрики, монетизация, запреты.

## Ключевые факты (проверено)

- Доступно сегодня: погода/ветер (Open-Meteo), прогноз воздуха CAMS (Open-Meteo AQ), стройки и разрешения (data.mos.ru, нужен бесплатный ключ).
- Недоступно: пробки (Яндекс ~195 тыс. ₽/год, ЦОДД по запросу), афиша (KudaGo закрыл API), замеры воздуха (только сайт Мосэкомониторинга).
- **Юридический блокер монетизации:** бесплатный тариф Open-Meteo — только non-commercial; коммерция требует платного плана (~$29/мес) `[проверить перед продажами]`.
